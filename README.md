# Amanda — Site de Padaria


## 📌 Sobre o projeto

O objetivo é desenvolver uma página moderna para apresentar a marca Amanda, seus produtos e sua história, transmitindo uma sensação de tradição, qualidade e produção artesanal.

O projeto está sendo desenvolvido por componentes, seguindo o wireframe criado previamente.

## 🎨 Identidade visual

A interface utiliza uma estética:

- Artesanal
- Elegante
- Aconchegante
- Premium
- Inspirada em padarias tradicionais

### Paleta de cores

- 🤎 Marrom escuro — `#2B1D1A`
